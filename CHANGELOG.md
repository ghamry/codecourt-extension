## [0.1.0] - TBD

### Added (Planned)
- OAuth2 authentication with Code Court
- Browse snippets in sidebar tree view
- Insert snippets at cursor or replace selection
- Create snippets from selected code
- Search snippets by title, language, tags
- Auto-refresh on startup
- Secure token storage in VS Code SecretStorage

### Security
- HTTPS-only communication with API
- Secure token storage using VS Code SecretStorage
- No third-party data sharing
