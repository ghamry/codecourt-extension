## 📱 Reddit Post (r/vscode, r/programming)

**Title:** [Open Source] I built a VS Code extension to stop context-switching to find code snippets

**Body:**

Hey r/vscode,

I got tired of opening my browser, searching through my snippet library, copying code, and switching back to VS Code 20+ times a day. So I built an extension that brings all my Code Court snippets directly into the editor.

**Key features:**
- One-click OAuth (no manual token nonsense)
- Instant search/filter in sidebar
- Create snippets from selected code in 3 seconds
- Smart variables support (${TM_FILENAME}, $1, ${2:default}, etc.)
- Hover to preview code before inserting
- Edit/delete right from VS Code
- Private/Protected/Public visibility controls

**Tech stack:**
- TypeScript + Webpack
- Axios for API calls
- VS Code SecretStorage for auth tokens
- Next.js backend with Prisma + PostgreSQL

**It's 100% free.** No freemium BS, no data collection, no ads.

**Coming soon:** MCP server integration so Claude Desktop can access your snippets natively (think "use my auth snippet" and Claude just knows).
